Privacy Policy

This app ("StockBriefingBot") is a personal tool used only by its owner.

Data accessed

The app requests permission to upload videos to the owner's own YouTube channel (YouTube Data API, upload scope). It does not read, collect, or store any other Google user data.

Data storage and sharing

OAuth tokens are stored only on the owner's own server. No user data is shared, sold, or transferred to any third party.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
